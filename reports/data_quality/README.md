# Data Quality Report (Phase 1)

Generated by `notebooks/01_data_profiling.ipynb` via `src/data_quality/`.

- `data_quality_report.md` / `.csv` — one row per dataset: rows, columns,
  missing %, duplicate rows, critical/warning issue counts, verdict
  (PASS/WARN/FAIL).
- `data_quality_issues.csv` — one row per individual finding (which check,
  which column, how many rows, detail) for drill-down.

Regenerate after any change to `src/data_quality/dataset_specs.py` or to the
raw data under `data/raw/`. A `FAIL` verdict must be resolved, or explicitly
accepted with a documented reason, before Phase 2 loads that dataset into
`staging`.
