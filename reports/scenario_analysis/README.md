# Scenario Analysis (Phase 9)

Generated by `notebooks/09_scenario_analysis.ipynb` via
`src/scenario_model/`, the same engine backing `POST /api/v1/scenario/simulate`.

- `scenario_comparison.csv` / `.md` — baseline vs. 8 representative
  scenarios across the full demand/lead-time/transport-cost parameter
  ranges, side by side.

Every figure is produced by the model in `src/scenario_model/engine.py`
from the real warehouse baseline in `src/scenario_model/data.py` — none
hardcoded. The model calibrates its safety-stock assumption to reproduce
the real observed baseline stockout rate exactly (see `engine.py`'s
docstring), so the swings under stress scenarios reflect how thin this
operation's actual buffer is, not an arbitrary modeling choice. Regenerate
after any change to the underlying warehouse data (i.e. after `make etl`).
